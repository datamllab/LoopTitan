          06An open record

          Declared, checked, in the open.

          1. 1DeclareThe study fixes its arms, its controlled fields and its adaptable fields.
          2. 2CheckEvery run is checked against the declaration.
          3. 3RecordRuns, failures and refuted predictions stay in the public issues.
          4. 4ContributeAn outside result enters by pull request as one folder; the bench check validates it, and every complete record is merged.Contributing guidebench.yml

          Acknowledgements

          LoopTitan stands on the work of others, and we thank them.

          TorchTitan is the training system we build on. CVSM, a protocol for research run through issues, shaped how our record is kept. Hugging Face Transformers and its Qwen3-MoE implementation are our independent reference.

          The authors of these public looped-model codebases shared the code whose designs we implement here, and we learned from it:
